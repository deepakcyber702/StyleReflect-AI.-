# StyleReflect AI 🤖👗

StyleReflect AI is an AI-powered smart fashion mirror application.
It helps users find the best outfit based on face shape and skin tone.

## 🚀 Features
- Camera photo capture
- Skin tone detection
- Outfit recommendation
- Style overlay (shirt, goggles)
- Offline demo mode
- Android TV display support

## 🛠 Tech Stack
- Frontend: React Native
- Backend: Node.js
- AI: Python (OpenCV)
- Cloud: Firebase
- Payments: Razorpay (UPI)
